# NeuroProgress

Disease-aware adaptive spatio-temporal brain graph learning for predicting
MCI -> Alzheimer's Disease progression within a future 21-month window,
using longitudinal ADNI data (brain morphometry + clinical/cognitive
features).

## Layout

- `data/raw/` - raw ADNI CSV (gitignored; restricted under the ADNI Data
  Use Agreement, never committed).
- `data/processed/` - cleaned/derived datasets (gitignored, same reason).
- `scripts/` - preprocessing pipeline, run in numeric order.
- `reports/` - audit and QA reports generated by the scripts (safe to
  commit: aggregate statistics only, no row-level patient data).

## Ground rules (from the project spec)

- Patient-level splitting only - all visits for a given `RID` stay in one
  split.
- No future-derived information (`FIRST_AD_DATE`, `DAYS_TO_FIRST_AD`, or
  anything computed from a visit later than the prediction point) may enter
  the feature matrix.
- ST* -> brain ROI mapping must be verified against an ADNI data
  dictionary before the anatomical prior graph is frozen, not guessed.
- No fabricated statistics or results - every number in `reports/` is
  computed directly from the data.
